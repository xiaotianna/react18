# 22-SchedulerMinHeap

## 最小堆

优先级调度算法就是最小堆

最小堆是一种经过排序的完全二叉树，父节点要比每个子节点的值小

- 编号关系：
  - 左子节点编号 = 父节点编号 / 2
  - 右子节点编号 = 左子节点 + 1
- 索引关系：
  - 左子节点索引 = (父节点索引 \* 2) + 1
  - 右子节点索引 = 左子节点 + 1

## SchedulerMinHeap.js

- `peek()` 查看堆的顶点
- `pop()` 弹出堆的顶点后需要调用 `siftDown` 函数向下调整堆
- `push()` 添加新节点后需要调用 `siftUp` 函数向上调整堆
- `siftDown()` 向下调整堆结构，保证最小堆
- `siftUp()` 需要向上调整堆结构，保证最小堆
